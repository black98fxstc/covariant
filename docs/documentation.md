Leonard provides geometric flow cytometry analysis integrated with standard laboratory workflows.

## System Requirements

- **Supported Platforms**: macOS and Windows workstations.
- **Hardware**: Any machine suitable for running FlowJo.

## Standard Workflow

1. **Workspace Input**: Open FlowJo workspace files (`.wsp`) or supported raw data files.
2. **Population & Dimension Selection**: Select a sample, choose analytical dimensions, and target previously gated subpopulations.
3. **Run Analysis**: Execute Exhaustive Projection Pursuit or Laplacian Clustering with Covariant Statistics.
4. **Export Results**: Review generated reports and export sortable gating trees.

## Getting Started

- **Downloads**: Download pre-built packages from [GitHub Releases](https://github.com/black98fxstc/covariant/releases/latest).
- **Installation**: Follow the build and installation guide in the [Covariant README](https://github.com/black98fxstc/covariant#readme).
- **Security**: Review the repository [Security Policy](https://github.com/black98fxstc/covariant/security/policy).
