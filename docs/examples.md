Example reports illustrate the outputs and visual summaries generated by Leonard during flow cytometry analysis.

## Available Report Types

- **Exhaustive Projection Pursuit Reports**: Interactive split trees and 2D projection plots highlighting identified population boundaries.
- **Laplacian Clustering Reports**: Cluster visualizations across 2D, 3D, and 4D projections accompanied by covariant shape statistics.
